\# One Earth Legacy



One Earth Legacy is a full-stack donation and public legacy platform where donors can select a mission, choose a specific impact path, create a public legacy tile, and complete donation checkout through Stripe.



The project includes a React frontend, Node.js/Express backend, MongoDB Atlas database, Stripe checkout, Stripe webhook support, public leaderboard, public audit records, public profiles, and donation success flow.
